# Bundled fonts

These unmodified font files are distributed under the SIL Open Font License 1.1, separately from the repository's MIT license. Each family includes its copyright attribution and OFL notice. Keep the corresponding notice when redistributing that family.

Families: Inter, Source Serif 4, Fraunces, Inter Tight, Fira Code and JetBrains Mono. Each includes regular (400), medium (500) and semibold (600) upright fonts served locally by styles/fonts.css. These are full font responses supplied by Google Fonts, not proprietary design-tool files.

Retrieved from the Google Fonts CSS service and its official font distribution on November 5, 2026. Family information: https://fonts.google.com/ . Font loading uses font-display: swap; no third-party font request is made by the previews. Native applications must register the files using platform APIs. Additional scripts, styles or weights may require additional licensed font assets.

Copyright holders and license text are retained. Parenthetical upstream repository URLs have been omitted from copyright headings to follow this collection's repository-link policy.

## Web compression

WOFF2 copies are generated from the bundled TTFs with fontTools 4.68.0 and Brotli 1.2.1, retaining glyphs, names and the accompanying licenses. TTF originals remain available. styles/fonts.css uses WOFF2; preserve both the font assets and per-family OFL notices when redistributing. No glyph subsetting was applied.
