# Getting help

The [Pagelove organization](https://github.com/pagelove) and repository contributors maintain this collection. Support happens through this repository's [GitHub Issues](https://github.com/pagelove/design-system/issues). Discussions are not enabled, and there is no guaranteed response time.

## Before opening an issue

1. Follow the [quick start](README.md#get-started) and check the [documentation index](docs/README.md).
2. Read the [support contract](docs/support.md) for format maturity and verification boundaries. An exported file does not imply a verified live-tool import.
3. Search existing issues for the same problem.

## Questions, bugs and requests

- **Usage question:** [open an issue](https://github.com/pagelove/design-system/issues/new) with your goal, selected design/mode, format and what you tried.
- **Bug:** use the [bug-report template](https://github.com/pagelove/design-system/issues/new?template=bug_report.md). Include expected behavior, actual behavior and a small reproduction.
- **Improvement:** use the [change-request template](https://github.com/pagelove/design-system/issues/new?template=feature_request.md). Describe the consumer need and an example rather than only requesting another component.
- **Contribution:** follow [CONTRIBUTING.md](CONTRIBUTING.md) and describe the scope before substantial implementation.

For browser problems, include the browser/OS and relevant screenshot. For generated files, include the collection version or commit, source change, build command and output path. For accessibility problems, include the keyboard or assistive-technology steps and observed barrier.

Keep reports public-safe: remove credentials, private project data and personal filesystem paths. If the concern is a vulnerability, do not post exploit details in a public issue. Use GitHub's private reporting option if available; otherwise request a private contact route without disclosing the sensitive details.
