## Suggested reading paths

- **App builders:** selected design's `DESIGN.md`, design selection, components, patterns, polish and accessibility. Add document-first guidance when designing app data and editing.
- **Design-tool users:** selected design's `exports/manifest.json`, formats, and the support contract. Use mode-specific Stitch guides for an exact mode.
- **Contributors:** [CONTRIBUTING.md](../CONTRIBUTING.md), repository map and the guide for the area being changed.
- **AI agents:** [AGENTS.md](../AGENTS.md), the catalog and selected design guide. [llms.txt](../llms.txt) is a discovery index; context bundles are optional, not a requirement to load everything.
